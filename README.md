# Capybara Typing Game

A free, gentle typing game for kids who don't know how to type yet. Press the glowing key to toss a yuzu into Mochi the capybara's hot spring.

**Play it:** https://istatler.github.io/capybara-typing-game/

Made by a parent for their 7-year-old. Kids type their own name at the start and the game uses it.

## How it teaches

- 17 levels, one finger at a time. It starts with F and J (the keys with bumps), then adds keys and short reaches, then words, then short sentences.
- 10 harder bonus levels after that: long words, the comma and period, and sentences. Two twists:
  - **Finger Check:** before each word, Mochi asks which finger types one of its letters, and the kid taps that finger on a picture of two hands.
  - **No Peeking:** the keys stop glowing, so kids find them by feel. One wrong press brings the glow back.
- The on-screen keyboard is colored by finger, and a pair of hands shows which finger to use for every key.
- A voice reads each letter and word out loud, so kids who are still learning to read can play.
- No timer and no losing. A wrong key gets a hint, not a penalty.
- Each finished level brings a new animal friend into the bath.

## No ads, no account, no tracking

The whole game is one HTML file with no build step and no server. The only outside request is Google Fonts. Progress is saved in your own browser (localStorage) and never leaves your device.

## Run it yourself

Download `index.html` and open it in any browser. Use a real keyboard for the best experience.
